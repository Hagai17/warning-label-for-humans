A tiny Python program that writes one safety warning label for human beings to `/output/entry.txt`: a single line of at most 160 characters in the exact wording and rhythm of a printed appliance label, true about how people actually behave — this unit ignores the label it is printed on, skips the manual, assembles itself wrong, and spends years blaming the manufacturer. The line was picked by drafting fourteen candidates and duelling them pairwise on the bounty judge's own criteria — funniest first, then a laugh that lands in one read with the turn in the last few words, truth about people in general, authentic label form, and full use of the line with no filler. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
